# Мусхаф `/mushaf/*` — сверка с Sajda (Taiga #28)

Дата: 2026-09-26. Скриншоты нашего мусхафа: `qa-screens/2026-09-26-mushaf-sajda/`.

## Как сверялось

Режим мусхафа в Sajda есть только в мобильном приложении, поэтому сверка шла по тому, что Sajda
показывает публично:

- скриншоты приложения в [Google Play](https://play.google.com/store/apps/details?id=com.raimbekov.android.sajde&hl=ru)
  и [App Store](https://apps.apple.com/ru/app/sajda-время-намаза-коран/id517254891) — на двух из них открыт
  мусхаф (стр. 151 «Аль-Араф» и стр. 601 «Аль-Аср / Аль-Хумаза / Аль-Филь») и список закладок;
- веб-версия Корана [sajda.com/ru/quran](https://sajda.com/ru/quran/1) — панели «Таджвид» (легенда цветов)
  и «Настройки» (таджвид, перевод, шрифт, тема), нижняя панель чтения;
- описание и история версий в сторах («разные стили мусхафа», «цветной таджвид», «контекстное меню в
  режиме мусхафа: избранное и заметки», «Коран без интернета» в Sajda+).

## Замечания владельца к PR #1 — тоже закрыты

- листание справа налево и плавный свайп на телефоне;
- «снизу поехала вёрстка» — тулбар стал строкой сетки, таб-бар в мусхафе скрыт, плеер встаёт над тулбаром;
- вместо «рандомных букв» при медленной сети — скелетон строк (`mobile-skeleton-slow-font`), следующие страницы
  качаются заранее, мусхаф можно скачать целиком;
- при увеличении строки переносятся по словам и страница прокручивается вниз (`mobile-zoom-160`);
- во весь экран — только текст, без стрелок и рамок (`mobile-immersive`, `desktop-immersive`);
- шторка по касанию аята работает, в том числе на страницах, дорисованных при листании.
